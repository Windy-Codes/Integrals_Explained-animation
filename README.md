# 📐 Integrals Explained — Manim Animation

This project is a Manim-based animation that visually demonstrates how definite integrals work.  
It covers the function plot, Riemann sums, subdivision refinement, and the transition from finite rectangles to the integral formula.

## 🎬 What This Animation Shows

- Title and intro animation  
- Function plot on coordinate axes  
- Marking the interval [a, b]  
- Highlighted integral area  
- Increasing subdivisions: 4 → 8 → 16 → 32 → 64  
- Smooth rectangle morphing using Riemann sums  
- Final transition to the definite integral formula  
- Clean Manim-style presentation

## 🧠 Concepts Demonstrated

- Area under a curve  
- Riemann rectangles  
- Limit of subdivisions  
- Definite integral representation  

## 🛠️ Technologies Used

- **Manim CE**
- **Python 3**
